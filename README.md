Estrutura Raiz (Configurações e Projeto)app/: Pasta que contém o código principal da sua aplicação (telas, componentes e lógica do React Native/Expo).assets/: Diretório para arquivos estáticos como imagens, fontes e ícones utilizados no aplicativo..vscode/: Pasta de configurações do editor Visual Studio Code, que guarda preferências específicas para o projeto.app.json: Arquivo de configuração principal do Expo, onde você define o nome do app, ícone, versão e outras propriedades globais.package.json: O "coração" do projeto. Lista todas as dependências (bibliotecas) e as versões que o aplicativo usa, além de comandos (scripts) para rodar a aplicação.package-lock.json: Arquivo gerado automaticamente que "trava" as versões exatas das bibliotecas, garantindo que o app funcione de forma idêntica em qualquer computador.eslint.config.js: Arquivo de configuração do ESLint, usado para padronizar o código e evitar erros de digitação ou más práticas.tsconfig.json: Arquivo de configuração do TypeScript, caso o seu projeto ou algumas das aulas usem tipagem estática..gitignore: Lista de arquivos e pastas que o Git deve ignorar e não enviar para o GitHub (como a pasta de bibliotecas pesadas).README.md: O arquivo de manual do projeto. Serve para você escrever um resumo sobre o que o app faz e como executá-lo.📚 Estrutura das Aulas (Exercícios Práticos)aula01 / Basico.js: Introdução aos conceitos iniciais de JavaScript e à sintaxe fundamental que será usada no desenvolvimento mobile.aula02: Aulas focadas na estruturação da lógica básica e manipulação de blocos de código (provavelmente laços de repetição ou condicionais).aula03 / numeros.js e funcoes.js: Foco em operações matemáticas com variáveis numéricas e na criação/chamada de funções (blocos de código reutilizáveis).aula04: Consolidação do que foi aprendido com foco em organizar o layout da interface usando as imagens da pasta assets/images no app.
